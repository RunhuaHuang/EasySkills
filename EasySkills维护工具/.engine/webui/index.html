Usage Guide

Everything you need to know to get the most out of EasySkills.

WebUI Quick Start

1
Open the Dashboard

After installation, open http://127.0.0.1:6633. The Dashboard shows the central skill library path, watcher status, and current linked agent count.

2
Import or review skills

Go to Skills, click Import Skill, choose a folder that contains SKILL.md, and EasySkills copies it into the central skill library.

3
Connect skill targets

Stay on Skills and connect the detected Agents that should receive the central skill library. Use Agent Config only when a path needs maintenance.

WebUI Control Map

Use the tabs in this dashboard as your main workflow. Each tab handles one part of skill management:

Dashboard

Check watcher status, run manual synchronization, and prune invalid links when folders were moved or deleted outside the WebUI.

Skills

Manage the central skill library and connect or disconnect its Agent sync targets in one workspace.

Agent Config

Maintain both skills-folder and global instruction-file paths, including custom registrations and non-standard locations.

About

Check the installed version, compare the latest release, and trigger an update through the local backend.

How to Restart EasySkills

If the WebUI port 6633 is unreachable or the background watcher stops working, you can easily restart them:

A
Double-click Start Launchers (Simplest)
Locate the EasySkills维护工具 directory in your ~/EasySkills folder and double-click:
• macOS: macOS/启动.command
• Windows: Windows/启动.bat
This will automatically start the background watcher daemon and open the WebUI.
B
Terminal Commands
macOS / Linux: 
bash ~/EasySkills/EasySkills维护工具/.engine/deploy.sh --unwatch
bash ~/EasySkills/EasySkills维护工具/.engine/deploy.sh --watch
bash ~/EasySkills/EasySkills维护工具/.engine/deploy.sh --webui
Windows (PowerShell): 
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\EasySkills维护工具/.engine\deploy.ps1" -Unwatch
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\EasySkills维护工具/.engine\deploy.ps1" -Watch
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\EasySkills维护工具/.engine\deploy.ps1" -WebUI

How to Update EasySkills

Keeping EasySkills updated ensures compatibility with new AI agents and brings bug fixes:

A
WebUI One-click Update (Recommended)

Go to the About section in this WebUI, check for new versions, and click the Update button. It preserves your custom configurations, custom agent paths, and tokens automatically, backing up the old engine to .maintenance-bak.

B
Terminal Re-installation
You can also re-run the Quick Start installation script. It will securely pull the latest repository changes:
• macOS / Linux: curl -fsSL https://raw.githubusercontent.com/RunhuaHuang/EasySkills/main/install.sh | bash
• Windows: irm https://raw.githubusercontent.com/RunhuaHuang/EasySkills/main/install.ps1 | iex

Managing skills in the WebUI

Import a skill folder

Installed Directory Structure

~/EasySkills/
├── EasySkills维护工具/           # 用户可见的维护入口
│   ├── macOS/                   # 启动 / 关闭.command
│   ├── Windows/                 # 启动 / 关闭.bat
│   ├── README_SYSTEM.md         # 系统说明文档
│   └── .engine/                 # 隐藏引擎 (excluded from mapping)
│       ├── deploy.sh / deploy.ps1 # Mapping & CLI engine
│       ├── webui.py / webui.ps1   # WebUI backend (port 6633)
│       ├── launchers/             # 启动/关闭/卸载脚本
│       └── custom-targets.txt     # User config (custom agent paths)
└── [YourSkills]/              # Drop your custom skills here

The root directory is kept clean. README, LICENSE, and install scripts exist only in the Git repository for GitHub display.

Notes

  • Windows Defender — If Windows Defender flags EasySkills, you can whitelist the ~/EasySkills folder in Windows Security settings.
  • Watcher Scope — The watcher monitors only the top-level of ~/EasySkills (folder additions/removals). It does not watch inside subdirectories since skills are symlinked. If ~/.proma exists, Proma workspace skills folders are polled every 5 minutes.
  • WebUI Port — The WebUI listens on 127.0.0.1:6633 only. It does not accept connections from other machines.

Rules Channel Quick Start

1
Create Modular Rules

Go to the Rules page, click New Rule, and write your prompt or instructions in Markdown (e.g. code style, testing guidelines).

2
Inject into Agents

Under the list of Agents, check the agents you want this rule block to apply to. EasySkills compiles all rules and writes them automatically.

3
Preserve Custom Changes

EasySkills wraps its compiled block in begin/end markers. You can write your own instructions outside this block, and they will never be overwritten.

How Rule Injection Works

The Rules synchronization channel uses a non-destructive managed block injection mechanism to keep agent configurations clean:

1
Compilation & Concatenation

All `.md` files inside the ~/EasySkills/instructions directory are concatenated together alphabetically.

2
The Managed Block

The compiled text is wrapped inside <!-- EasySkills:begin --> and <!-- EasySkills:end --> comments.

3
Non-destructive Update

EasySkills locates this block in each target file (e.g., CLAUDE.md) and updates it, leaving any text outside the block untouched.

Rule Configuration & Paths

  • Rules Library Path: Modular rules are stored in ~/EasySkills/instructions/ (e.g. ~/EasySkills/instructions/rule1.md). You can drop any markdown file here directly.
  • Global Instruction File Paths: Configure target paths in the Agent Config tab (e.g. ~/.claude/CLAUDE.md for Claude Code, ~/.cursor/AGENTS.md for Cursor).
  • State Tracker: The active write targets and metadata are stored in ~/EasySkills/.easyskills-instruction-state.json.
