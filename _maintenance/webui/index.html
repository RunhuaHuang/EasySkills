Usage Guide

Everything you need to know to get the most out of EasySkills.

Quick Start

1
Install EasySkills

Run the one-line install command, or double-click the installer for your platform. The engine is installed to ~/EasySkills.

2
Drop Your Skills

Place any skill folder into ~/EasySkills. The background watcher detects it and maps it to all installed agents within seconds.

3
Done — All Agents Synced

Every supported agent (Claude, Gemini, Cursor, etc.) now sees your skill via symlink. Edit the skill once, all agents reflect it instantly.

Installation Methods

Method A: One-Line Install (Recommended) 
 curl -fsSL https://raw.githubusercontent.com/RunhuaHuang/EasySkills/main/install.sh | bash

 irm https://raw.githubusercontent.com/RunhuaHuang/EasySkills/main/install.ps1 | iex
Method B: Double-Click

Clone or download the repo, then double-click install_mac.command (macOS) or install_windows.bat (Windows).

Method C: Let Your AI Agent Do It

Just tell your agent: "Help me initialize EasySkills". It reads the SKILL.md, runs the script, and asks about custom paths.

Starting & Stopping Services

EasySkills consists of two components: the background watcher daemon and the local WebUI panel. Here is how to control them:

1. Background Watcher Daemon

Automatically detects changes and syncs your skills in real-time.

  • Start: Click "Start Watcher" on the Dashboard, or run CLI: 
    # macOS:
bash ~/EasySkills/_maintenance/deploy.sh --watch
# Windows:
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\_maintenance\deploy.ps1" -Watch
  • Stop: Click "Stop Watcher" on the Dashboard, or run CLI: 
    # macOS:
bash ~/EasySkills/_maintenance/deploy.sh --unwatch
# Windows:
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\_maintenance\deploy.ps1" -Unwatch
2. WebUI Dashboard Control

The visual panel running locally at http://localhost:6633.

  • Start: Double-click the launcher script, or run CLI: 
    # macOS:
~/EasySkills/_maintenance/macOS/Start — 启动.command
# Windows:
~/EasySkills/_maintenance/Windows/Start — 启动.bat
# CLI:
deploy.sh --webui / deploy.ps1 -WebUI
  • Stop: Simply close the launcher terminal window, or press Ctrl+C in the CLI terminal.

WebUI Dashboard

After installation, open http://localhost:6633 in your browser, or launch manually:

# macOS / Linux
bash ~/EasySkills/_maintenance/deploy.sh --webui

# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\_maintenance\deploy.ps1" -WebUI

The dashboard lets you monitor watcher status, browse skills, connect/disconnect agents, edit paths, and check for updates. Requires Python 3 (macOS/Linux) or PowerShell 5.1+ (Windows).

CLI Reference

# macOS
bash ~/EasySkills/_maintenance/deploy.sh [option]

# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\_maintenance\deploy.ps1" [option]
Option Description
--syncSync all skills to all agents (default)
--listList all active mappings
--add <path>Add & persist a custom agent path
--remove <path>Remove a persisted custom path
--watchInstall the background watcher daemon
--unwatchUninstall the background watcher daemon
--cleanupRemove all EasySkills symlinks
--statusShow watcher and mapping health status
--webuiStart the local WebUI on port 6633
--helpShow help

Custom Path Overrides

Override any agent's default skills path via _maintenance/custom-targets.txt using the AgentName=/new/path syntax. Useful when an agent is installed in a non-standard location.

# Example: custom-targets.txt
MyCustomAgent=/opt/my-agent/skills
Cursor=/Users/me/custom-cursor/skills

You can also add custom paths via the CLI (deploy.sh --add /path), the Agents tab in this WebUI, or by asking your AI agent.

Installed Directory Structure

~/EasySkills/
├── SKILL.md                   # AI Agent skill interface
├── _maintenance/              # Core engine (excluded from mapping)
│   ├── macOS/                 # Double-click launchers
│   │   ├── Start — 启动.command
│   │   └── Uninstall — 卸载.command
│   ├── Windows/               # Double-click launchers
│   │   ├── Start — 启动.bat
│   │   └── Uninstall — 卸载.bat
│   ├── deploy.sh / deploy.ps1 # Mapping & CLI engine
│   ├── webui.py / webui.ps1   # WebUI backend (port 6633)
│   ├── custom-targets.txt     # User config (custom agent paths)
│   └── .version               # Version tracker
└── [YourSkills]/              # Drop your custom skills here

The root directory is kept clean. README, LICENSE, and install scripts exist only in the Git repository for GitHub display.

Notes

  • Windows Defender — If Windows Defender flags EasySkills, you can whitelist the ~/EasySkills folder in Windows Security settings.
  • Watcher Scope — The watcher monitors only the top-level of ~/EasySkills (folder additions/removals). It does not watch inside subdirectories since skills are symlinked. If ~/.proma exists, Proma workspace skills folders are polled every 5 minutes.
  • WebUI Port — The WebUI listens on localhost:6633 only. It does not accept connections from other machines.
