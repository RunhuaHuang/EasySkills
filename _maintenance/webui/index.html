Usage Guide

Everything you need to know to get the most out of EasySkills.

WebUI Quick Start

1
Open the Dashboard

After installation, open http://127.0.0.1:6633. The Dashboard shows the central skill library path, watcher status, and current linked agent count.

2
Import or review skills

Go to Skills, click Import Skill, choose a folder that contains SKILL.md, and EasySkills copies it into the central skill library.

3
Connect missing agents

Go to Agents. If an agent is not listed, paste its skills-folder absolute path and register it as a custom channel.

WebUI Control Map

Use the tabs in this dashboard as your main workflow. Each tab handles one part of skill management:

Dashboard

Check watcher status, run manual synchronization, and prune invalid links when folders were moved or deleted outside the WebUI.

Skills

Import a local skill folder, confirm which folders contain SKILL.md, and delete central skills when they are no longer needed.

Agents

Review detected agents, disconnect agents you do not want, or register an unsupported agent by entering its skills folder.

About

Check the installed version, compare the latest release, and trigger an update through the local backend.

Managing skills in the WebUI

1
Import a skill folder

Open Skills, click Import Skill, and select the folder itself. The folder must contain SKILL.md at its root.

2
Let EasySkills sync it

After import, EasySkills places the folder under the central skill library and refreshes linked agents automatically.

3
Delete with confirmation

Use the trash button on a skill card only when you want to remove that central folder from EasySkills.

Connecting agents in the WebUI

The Agents tab is where EasySkills connects the central skill library to each agent's own skills directory.

Review detected agents

Cards marked as discovered are paths EasySkills can map into right away.

Register an unsupported agent

If your agent is missing, paste its absolute skills-folder path into the registration bar and click Register.

Disconnect when needed

Use Disconnect or Deregister for channels you no longer want EasySkills to maintain.

Advanced CLI fallback

Most users should use the WebUI. These commands are useful for automation, recovery, or headless machines:

macOS / Linuxbash ~/EasySkills/_maintenance/deploy.sh --cleanupRemove broken EasySkills links if an external tool moved folders.
Windowspowershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\_maintenance\deploy.ps1" -CleanupRemove broken EasySkills links if an external tool moved folders.

Windowspowershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\EasySkills\_maintenance\deploy.ps1" -WebUIStart the local WebUI on port 6633.

Installed Directory Structure

~/EasySkills/
├── README_SYSTEM.md           # System documentation
├── _maintenance/              # Core engine (excluded from mapping)
│   ├── macOS/                 # Double-click launchers
│   │   ├── Start — 启动.command
│   │   └── Uninstall — 卸载.command
│   ├── Windows/               # Double-click launchers
│   │   ├── Start — 启动.vbs
│   │   └── Uninstall — 卸载.bat
│   ├── deploy.sh / deploy.ps1 # Mapping & CLI engine
│   ├── webui.py / webui.ps1   # WebUI backend (port 6633)
│   ├── custom-targets.txt     # User config (custom agent paths)
│   └── .version               # Version tracker
└── [YourSkills]/              # Drop your custom skills here

The root directory is kept clean. README, LICENSE, and install scripts exist only in the Git repository for GitHub display.

Notes

  • Windows Defender — If Windows Defender flags EasySkills, you can whitelist the ~/EasySkills folder in Windows Security settings.
  • Watcher Scope — The watcher monitors only the top-level of ~/EasySkills (folder additions/removals). It does not watch inside subdirectories since skills are symlinked. If ~/.proma exists, Proma workspace skills folders are polled every 5 minutes.
  • WebUI Port — The WebUI listens on 127.0.0.1:6633 only. It does not accept connections from other machines.
